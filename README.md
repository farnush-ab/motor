# موتوسنج | MOTOSANJ

وب‌سایت معرفی خدمات **کارشناسی موتورسیکلت پیش از خرید**.

سایت به‌صورت کاملاً اختصاصی و از پایه با HTML، CSS و JavaScript کدنویسی شده است.
**وردپرس، دیتابیس، پنل مدیریت و هیچ فریمورک یا کتابخانه‌ی بیرونی در آن به کار نرفته است.**

## ویژگی‌ها

- ⚡ **سرعت بالا** — بدون jQuery، بدون Bootstrap، بدون CDN؛ کل سایت چند صد کیلوبایت است
- 📱 **کاملاً واکنش‌گرا** — موبایل، تبلت و دسکتاپ
- 🌙 **قالب تیره با تم قرمز** مطابق طرح تأییدشده
- 🇮🇷 **راست‌به‌چپ (RTL)** با فونت وزیرمتن، به‌صورت میزبانی‌شده روی خود سایت
- ☎️ **بدون درگاه پرداخت، بدون چت آنلاین و بدون فروش محصول** — تنها راه ارتباطی، شماره تماس است
- 🔍 **بهینه برای گوگل** — متا تگ‌ها، sitemap، robots.txt و داده‌ی ساختاریافته
- ♿ **دسترس‌پذیر** — ناوبری با کیبورد، متن جایگزین تصاویر و احترام به تنظیم «کاهش حرکت»
- 📦 **مالکیت کامل کد** — هیچ وابستگی، اشتراک یا سرویس خارجی وجود ندارد

## اجرای محلی

هیچ فرآیند build ای لازم نیست. کافی است `index.html` را در مرورگر باز کنید.

برای تست دقیق‌تر (که مسیرها و فونت‌ها درست بارگذاری شوند) یک وب‌سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## انتشار روی هاست

کل محتویات این پوشه را در `public_html` هاست خود کپی کنید. همین.
سایت روی هر هاست اشتراکی، VPS یا سرویس‌های استاتیک (مثل GitHub Pages یا Cloudflare Pages) کار می‌کند.

## تصاویر

تصاویر فعلی همگی **SVG طراحی‌شده** هستند تا سایت حجم کمی داشته باشد و همه‌جا شارپ دیده شود.
برای جایگزینی با عکس واقعی، به بخش «تصاویر» در راهنمای مدیریت سایت مراجعه کنید.
